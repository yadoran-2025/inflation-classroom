✍️ 아날로그 손그림(Hand-drawn) SVG 기술 데모

니키 케이스(Nicky Case)의 흔들리는 핸드드론 벡터 라인 재현하기

💡 어떻게 컴퓨터 선을 "손그림"처럼 만드나요?

니키 케이스의 신뢰의 진화(The Evolution of Trust)에 쓰인 그래픽들은 일러스트레이터로 그린 매끄러운 선이 아니라, 실제 연필이나 사인펜으로 슥슥 그은 듯 선이 미세하게 떨리고 구부러져 있으며, 채색이 외곽선에서 조금씩 삐져나와 따뜻한 느낌을 줍니다.

이 데모 페이지에서는 순수 SVG와 CSS만을 이용하여 이를 완벽하게 재현하는 3가지 비밀 기술을 직접 눈으로 비교할 수 있게 제작했습니다:

  • 비밀 1: SVG feTurbulence 노이즈 필터 - 완벽하게 뻗은 벡터 외곽선을 찌글찌글하게 뒤틀어 잉크가 밴 펠트펜 질감으로 바꿉니다.
  • 비밀 2: 프레임 wiggling (출렁임 효과) - 미세하게 다른 노이즈 시드를 가진 필터 2개를 교차 반복하여, 캐릭터가 살아 숨 쉬듯 외곽선이 바르르 wiggling하는 만화적 효과를 줍니다.
  • 비밀 3: 오프셋 채색 (Offset Fill) - 면 색상 칠하기를 외곽선 좌표에서 약간 어긋나게(translate) 처리하여, 초등학생이 색연필로 정겹게 삐쳐 칠한 손그림 느낌을 줍니다.

1. 선의 질감 비교 데모 (The Scale)

기존 정형화된 컴퓨터 SVG

Mechanical
수학적으로 정확하게 떨어져 다소 경직되고 영혼이 없어 보이는 정형화된 차트형 이미지입니다.

출렁이는 핸드드론(Hand-drawn) SVG

Wiggling & Offset
선들이 바르르 떨리며 춤추는 듯한 애니메이션과, 일부러 약간 어긋나게 칠한 수채화식 오프셋 채색이 가미되어 손맛을 극대화합니다.

2. 캐릭터/소품 손그림 데모 (News Analysis)

기존 정형화된 컴퓨터 SVG

Mechanical
수학적 선들로만 이루어져 있어 교과서 구석에 있는 흑백 픽토그램 아이콘 같은 느낌을 줍니다.

출렁이는 핸드드론(Hand-drawn) SVG

Wiggling & Offset
바르르 떠는 필터 덕분에 돋보기가 신문을 실제로 관찰하며 숨 쉬는 듯한 활력과 동적인 즐거움을 불어넣어 줍니다.

🛠️ 우리 프로젝트에 적용하는 방법

이 미세 흔들림(Wiggle) 필터는 별도의 무거운 외부 그래픽 소스 없이, 기존 React 코드 안에 매우 간단히 심을 수 있습니다.

1단계: `src/App.tsx`의 적절한 빈 곳(예: `App` 컴포넌트 내부 최상단)에 아래의 `` 필터 마크업을 단 한 번만 복사해서 붙여넣습니다: 

<svg style={{ position: 'absolute', width: 0, height: 0 }} aria-hidden="true">
  <defs>
    <filter id="rough-edge-1" x="-10%" y="-10%" width="120%" height="120%">
      <feTurbulence type="fractalNoise" baseFrequency="0.04" numOctaves="3" seed="1" result="noise" />
      <feDisplacementMap in="SourceGraphic" in2="noise" scale="3.5" xChannelSelector="R" yChannelSelector="G" />
    </filter>
    <filter id="rough-edge-2" x="-10%" y="-10%" width="120%" height="120%">
      <feTurbulence type="fractalNoise" baseFrequency="0.04" numOctaves="3" seed="8" result="noise" />
      <feDisplacementMap in="SourceGraphic" in2="noise" scale="3.5" xChannelSelector="R" yChannelSelector="G" />
    </filter>
  </defs>
</svg>

2단계: `src/index.css` 최하단에 선이 wiggling하는 CSS 애니메이션 클래스를 붙여넣습니다: 

.wobbly-hand-drawn {
  animation: svg-wiggle-effect 0.3s steps(2) infinite;
}

@keyframes svg-wiggle-effect {
  0% { filter: url(#rough-edge-1); }
  50% { filter: url(#rough-edge-2); }
}

3단계: wiggling이 필요한 SVG 태그들에 **`wobbly-hand-drawn`** 클래스를 부여하면, 완벽하고 부드러운 아날로그 손그림 효과가 뿜어져 나오게 됩니다!
